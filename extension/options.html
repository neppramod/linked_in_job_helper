Welcome! Set up in 3 steps

  1. Government and defense jobs: pick yes or no (required).
  2. Your skills: add what you're good at, so each job gets a fit rating.
  3. Cover letter: replace the [bracketed] parts of the template with your own text.

Then click Save settings at the bottom. You can come back here any time: right-click the extension icon → Options.

Two ways to set this up

Fill in this page and click Save settings, or edit SETUP.md in the extension folder with Notepad. The extension reads SETUP.md automatically when the file changes. If you use this page, click Download SETUP.md afterwards and put the file in the extension folder, so both stay the same.

2. Your skills

Write one skill per line. If a skill has other names, put them on the same line with | between them, for example Excel | spreadsheets. The extension looks for these words in each job and rates the job: Strong, Mixed or Weak.

If a job does not mention one of these, it is rated Weak. Leave this empty if you have none.

Skills you do not have, or work you do not want to do. The extension warns you when a job mentions them.

3. Hiding and warnings

One item per line. These are your own lists. They work whatever you picked in question 1.

4. Saving jobs

Clicking Save job in the popup copies the job to your clipboard, adds it to the Tracker, and writes the whole list to a CSV file you can open in Excel or Google Sheets.

Tip: close the file in Excel before saving a job, or Chrome may save a copy like jobs (1).csv. If Chrome asks where to save each time, turn off "Ask where to save each file" in Chrome's download settings.

Placeholders: {{COMPANY}} {{ROLE}} {{LINK}} {{DATE}}

5. Your cover letter

Replace everything in [square brackets] with your own words. These are filled in for each job: {{COMPANY}} {{ROLE}} {{DATE}} {{LINK}}. To make words bold, put ** on both sides. Start a line with # to make it a heading (for your name). Leave an empty line between paragraphs.

6. Backup

Save your settings to a file, or load them on another computer.
